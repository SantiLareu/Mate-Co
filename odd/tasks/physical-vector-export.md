## Architecture decisions (audit mvf6jiu8-1-68sb)
Fonts BLOCKED: editor uses only system proprietary fonts (DesignPanel.tsx:30-36 Georgia/Arial/Times New Roman/Trebuchet MS/Verdana); no @font-face/font files/parser deps anywhere; browser exposes no glyph outlines; existing outlines path is raster→VTracer (textOutlines.ts) — non-deterministic and forbidden. Per user decision fonts-block-gate: export fails closed for ANY composition containing texts with explicit code FONT_OUTLINES_UNAVAILABLE; evidence documented; text gate tests replace outline tests this stage; proposed safe future solution: bundled OFL font + outline parser (Stage 4, licensing decision).
Approved v3: sanitized full <svg> document (svgAssetImport) rendered via ephemeral Blob <image> — export must inline nested <svg> inside <g transform=translate/rotate/scale> with per-instance ID namespacing (DOM-based rewrite, never regex) for id/url(#)/href#/<style> selectors. Fail-closed scan: raster data:image/(png|jpeg|gif|webp|bmp|avif) payloads (svgAssetImport.ts:225 permits them), filter/fe* features, and <text>/<font-family> inside approved assets (fonts blocker applies to them too). v1/v2 controlled geometry exports directly (paths/transforms already validated data).
Knockouts: convert PhysicalReport LineKnockout[] → disk descriptors (distance=hypot, angleDegrees=atan2(y,x), radius=radiusMm) and band descriptors (radius=anchorRadiusMm, halfWidth=strokeWidthMm/2+1*sizeFactor, halfSpanDegrees, angleOffset) via export/geometry.ts helpers at center=0, mirroring productionSvg.ts linesGroup logic in mm. Round-cap delta documented. Text band requires halfSpanDegrees!=null AND baselineRadiusMm!=null else fail closed.
Contract: pure sync DOM-free core src/production-lab/exportSvg.ts buildLabPhysicalSvg({report,...}) → {ok:true,svg,meta}|{ok:false,code,reason}; deterministic (no Date/random); PhysicalComposition renders from same report; consistency test asserts exported numbers == rendered data-* attrs. Ring group id="lab-ring-reference" sibling of engraving group id="lab-engraving"; ring circles are MEASUREMENT REFERENCES (documented), not engraving paths. Impure helpers isolated: exportApprovedAsset.ts (DOM namespacing+raster/filter guard), exportTextOutlines.ts (font gate returning blocker today). Download via lab-local Blob helper. UI button in parsed-ok branch near strategy readout; enabled only when report ok/no texts/asset guards pass; status region shows file name+measures or blocker reason. Experimental label.
Export SVG root: xmlns, width="Xmm" height="Xmm", viewBox="0 0 X X" (mm=1unit), h=maxRadius+pad mirroring preview fit (consistent with PhysicalComposition.tsx:401-407 minus UI-only groups/labels/envelopes — UI ⌀ labels/envelopes/pending markers are display-only and excluded from export).
Determinism: same input → byte-identical output (sorted attrs, canonical number serialization consistent with existing String(number) practice); no timestamps in file.
